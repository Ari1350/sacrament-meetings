# Sacrament Meetings

A Next.js web application for organizing and viewing sacrament meeting information.

## Features

- View sacrament meetings
- View detailed meeting information
- View the current meeting
- Reusable React components
- API routes for meeting data
- Responsive design
- About page

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
